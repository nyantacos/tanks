# tanks

ブラウザで動く戦車の 3D シミュレーション。ルノー FT 軽戦車(機関銃型)と九七式中戦車 チハ(57mm砲・初期型)を選んで操作できます。
依存ライブラリなし、WebGL2 + ES modules のみ。

## 遊び方

| キー | 動作 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左旋回 / 右旋回 |
| Q / E | 砲塔 左 / 右 |
| R / F | 主砲(ルノー FT は機銃)上 / 下 |
| Space | 主兵装 発砲(FT は機銃の連射、チハは主砲) |
| G | 機銃 発砲(チハは車体機銃) |
| ← → ↑ ↓ | 車体機銃の向き(チハ) |
| H | 砲弾 被弾(18〜34 ダメージ) |
| J | 機銃弾 被弾(跳弾。まれに 1 ダメージ) |
| X | 敵砲撃 自動 ON/OFF |
| C | 迷彩 切替 |
| V | 視点 切替 |
| T | 車両 切替 |
| Enter | リセット |

耐久力はルノー FT が 100、チハが 160。砲弾の被弾ごとに 18〜34 減り、0 を割り込むと大破(砲塔が吹き飛び、操作不能)。
画面下のボタンでタッチ操作も可。

## ローカルで動かす

ES modules を使っているので、ファイルを直接開くのではなくローカルサーバー経由で開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 構成

| ファイル | 役割 |
|---|---|
| `main.js` | カメラ・HUD・ゲームループ(各モジュールの結線) |
| `tank.js` | 走行・砲塔・射撃・耐久力・大破の状態機械 |
| `input.js` | キーボードと画面ボタンをアクション名に統一 |
| `effects.js` | 発砲炎・曳光弾・爆発・煙・飛来砲弾 |
| `sfx.js` | WebAudio で合成する効果音 |
| `renderer.js` | WebGL2 描画(シャドウマップ・迷彩・焼けシェーダ) |
| `model.js` | ルノー FT の形状定義と車両仕様 |
| `chiha.js` | 九七式中戦車 チハの形状定義と車両仕様 |
| `track.js` | 履帯経路の生成(共通) |
| `geometry.js` | プリミティブ生成 |
| `math.js` | 行列・ベクトル演算 |

## 車両を追加するには

`chiha.js` と同じ形で、形状(`geo`)と仕様(`maxHp`・`maxSpeed`・`weapon` など)を返す `buildXxx()` を書き、`main.js` の `VEHICLES` と `index.html` の車両ボタンに追加します。
