# tanks

ブラウザで動くルノー FT 軽戦車(機関銃型・ベルリエ八角砲塔)の 3D シミュレーション。
依存ライブラリなし、WebGL2 + ES modules のみ。

## 遊び方

| キー | 動作 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左旋回 / 右旋回 |
| Q / E | 砲塔 左 / 右 |
| R / F | 機銃 上 / 下 |
| Space | 発砲(押し続けで連射) |
| H | 被弾(敵弾が飛来) |
| X | 敵砲撃 自動 ON/OFF |
| C | 迷彩 切替 |
| V | 視点 切替 |
| Enter | リセット |

耐久力 100。被弾ごとに 18〜34 減り、0 を割り込むと大破(砲塔が吹き飛び、操作不能)。
画面下のボタンでタッチ操作も可。

## ローカルで動かす

ES modules を使っているので、ファイルを直接開くのではなくローカルサーバー経由で開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 構成

| ファイル | 役割 |
|---|---|
| `main.js` | カメラ・HUD・ゲームループ(各モジュールの結線) |
| `tank.js` | 走行・砲塔・射撃・耐久力・大破の状態機械 |
| `input.js` | キーボードと画面ボタンをアクション名に統一 |
| `effects.js` | 発砲炎・曳光弾・爆発・煙・飛来砲弾 |
| `sfx.js` | WebAudio で合成する効果音 |
| `renderer.js` | WebGL2 描画(シャドウマップ・迷彩・焼けシェーダ) |
| `model.js` | ルノー FT の形状定義 |
| `geometry.js` | プリミティブ生成 |
| `math.js` | 行列・ベクトル演算 |
